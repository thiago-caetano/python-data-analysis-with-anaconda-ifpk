# 20 Everyday Algorithm Examples

## Português

Esta pasta contém **20 exemplos de algoritmos do dia a dia**, desenvolvidos para praticar lógica de programação de forma simples e objetiva.

Os exercícios foram pensados para ajudar no entendimento de etapas lógicas, sequência de ações, entrada e saída de dados, além da resolução de problemas comuns do cotidiano.

### Observação

Os exemplos desta pasta são introdutórios e servem como base para exercícios mais avançados no estudo de algoritmos e programação.

---

## English

This folder contains **20 everyday algorithm examples**, created to practice programming logic in a simple and objective way.

These exercises were designed to help with understanding logical steps, sequences of actions, input and output data, and solving common everyday problems.

### Note

The examples in this folder are introductory and serve as a foundation for more advanced exercises in algorithms and programming.
